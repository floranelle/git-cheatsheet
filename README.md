# Шпаргалка по Git

Здесь я собираю основные понятия и команды, которые помогают работать с Git.

## Основные понятия

- **Git** — система, которая сохраняет историю изменений проекта.
- **GitHub** — сервис для хранения Git-репозиториев и совместной работы.
- **Репозиторий** — проект вместе с историей его изменений.
- **Коммит** — сохранённое состояние проекта с описанием изменений.

## Работа с локальным репозиторием

- `git init -b main` — создать Git-репозиторий с начальной веткой main.
- `git status` — посмотреть состояние проекта: новые, изменённые и подготовленные файлы.
- `git add README.md` — подготовить текущие изменения файла README.md к коммиту.
- `git commit -m "Описание изменений"` — сохранить подготовленные изменения в истории проекта.
- `git log` — посмотреть историю коммитов.
- `git log --oneline` — посмотреть историю кратко: один коммит на строку.

### Как сохранить изменения

1. Изменить файл и сохранить его в редакторе.
2. Подготовить изменения командой `git add`.
3. Создать коммит командой `git commit`.

Команда `git add` подготавливает также удаление файла.
Коммит сохраняется локально, на компьютере.


## Работа с GitHub

Вместо `АДРЕС` в командах нужно подставить настоящий SSH- или HTTPS-адрес репозитория.

- `git remote add origin АДРЕС` — сохранить адрес удалённого репозитория под именем origin.
- `git remote -v` — посмотреть адреса связанных удалённых репозиториев.
- `git push -u origin main` — отправить ветку main на GitHub и запомнить связь с удалённой веткой.
- `git push` — отправить новые коммиты в связанную удалённую ветку.
- `git clone АДРЕС` — скачать репозиторий вместе с историей коммитов. Связь origin создаётся автоматически.
- `ssh -T git@github.com` — проверить SSH-подключение к GitHub.

На GitHub отправляются коммиты. Изменения нужно сначала сохранить в файле, подготовить через `git add` и включить в коммит.

## Форк и клонирование

**Форк** — своя копия чужого репозитория на GitHub. Создаётся кнопкой Fork. GitHub сохраняет связь с исходным проектом, но изменения в своём форке можно делать независимо.

**Клонирование** — создание локальной копии репозитория на компьютере командой `git clone`.

Перед клонированием можно перейти в домашнюю папку командой `cd ~`, чтобы проекты лежали рядом.

После клонирования нужно самостоятельно перейти в созданную папку командой `cd имя_папки`.
